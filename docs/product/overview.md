# Overview

`agtmux-term` is a tmux-first macOS cockpit for AI-agent-driven development.

The product centers on:

- real tmux sessions as visible runtime truth
- Ghostty as the terminal rendering and input authority
- agtmux daemon sync-v3 as metadata and health truth
- an app-owned control plane for browsing, binding, restore, and diagnostics

The app is not an embedded terminal platform or IDE shell. It is a companion
for real tmux sessions running locally or on remote hosts.
