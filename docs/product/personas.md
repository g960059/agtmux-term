# Personas

## Primary Persona

AI-heavy macOS developers who already use tmux and run multiple Claude Code,
Codex, or similar agent sessions in parallel.

They want to:

- browse local and remote sessions quickly
- see which sessions are running, idle, blocked, or degraded
- preserve normal terminal behavior instead of learning an app-owned terminal
- avoid duplicate terminals for the same logical session
- recover from stale bindings, host failures, and permission issues quickly
